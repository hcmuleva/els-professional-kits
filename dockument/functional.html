Karate Starter Kit - Professional Guide

Karate Starter Kit Generator - Complete Setup Guide

This starter kit generator creates a complete Karate API test automation project with three progressive levels.

📦 What's Included

  • Level 1 - Simple Feature files
  • Level 2 - Maven + Reports
  • Level 3 - Advanced: CI/CD + Test Data + Utilities

⚙️ Prerequisites

  • Java 8+
  • Maven
  • Node.js (optional, if integrating)

🚀 Steps to Generate Project

# Clone generator repo
git clone https://github.com/karatelabs/karate-starter-kit.git
cd karate-starter-kit

# Run generator
./generate-kit.sh

📂 Generated Project Structure

my-karate-project/
 ├── pom.xml
 ├── src/test/java
 │    ├── examples/
 │    └── runners/
 ├── src/test/resources/
 │    └── features/
 └── reports/

▶️ Run Tests

# Run all tests
mvn test

# Run specific tag
mvn test -Dkarate.options="--tags @smoke"

📊 Reports

  • HTML Reports → target/karate-reports/karate-summary.html
  • JUnit XML → target/surefire-reports/TEST-*.xml

Karate Starter Kit - Quick Reference Card

🚀 Quick Commands

# Generate kit (Linux/Mac)
./generate-kit.sh

# Generate kit (Windows)
generate-kit.bat

# Install dependencies
mvn clean install -DskipTests

# Run all tests
mvn test

🏷 Running by Tag

mvn test -Dkarate.options="--tags @smoke"
mvn test -Dkarate.options="--tags @regression"

🛠 Directory Structure

src/test/resources/features    → Feature files
src/test/java/examples         → Example Java classes
src/test/java/runners          → JUnit runners
reports                        → Test reports

📊 Reports

  • HTML: target/karate-reports/karate-summary.html
  • JUnit XML: target/surefire-reports/

🔑 Useful Snippets

🟢 Level 1 - Basic Authentication

Ideal For: Beginners, quick POCs, tutorials

4 Test Scenarios:
├── Register a new user
├── Login with username
├── Login with email
└── Get authenticated user info
    
Scenario: Register a new user
  * def username = 'user' + timestamp()
  * def email = username + '@test.com'
  
  Given path '/auth/local/register'
  And request { "username": "#(username)", "email": "#(email)", "password": "Test@123456" }
  When method POST
  Then status 200
  And match response.jwt == '#string'

🟡 Level 2 - Data Driven Testing

Ideal For: Intermediate users, regression, reusable patterns

Scenario Outline: Register multiple users
  * def uniqueUsername = '' + timestamp()
  * def uniqueEmail = uniqueUsername + '@test.com'
  
  Given path '/auth/local/register'
  And request
    """
    {
      "username": "#(uniqueUsername)",
      "email": "#(uniqueEmail)",
      "password": "",
      "first_name": "",
      "last_name": ""
    }
    """
  When method POST
  Then status 200

  Examples:
    | username   | password    | firstName | lastName |
    | john_user  | Pass@123456 | John      | Smith    |
    | jane_user  | Pass@123456 | Jane      | Doe      |

🔴 Level 3 - Advanced Testing

Ideal For: Experienced testers, production suites, CI/CD integration

Scenario: Update current user details
  * def newUsername = randomUsername()
  
  Given path '/users/' + currentUserId
  And header Authorization = 'Bearer ' + jwt
  And request { "username": "#(newUsername)" }
  When method PUT
  Then status 200
  And match response.username == newUsername
  And match response.id == currentUserId
